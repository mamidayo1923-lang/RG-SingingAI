<h1>#RG_SingingAI(EN)</h1>

Working_Title:RG_SingingAI   
Project_Name :TBD   

This project aims to build a model capable of singing by recreating the original human voice's timbre, intonation, and breath control as closely as possible, using AI technology and other techniques. Training datasets are created by recording the reference human voice as WAV files, extracting and analyzing features from them, and storing the data alongside MIDI files and other related assets.

This project is planned and developed by a single high school student. Since development is done on a PC with a daily one-hour limit set by my parents, progress takes place within very limited time. Updates may be slow, but development is moving as fast as possible, so your patience and understanding are greatly appreciated.

このプロジェクトは、AI技術およびその他の手法を用いて、元の人間の声にできるだけ近い声質、イントネーション、ブレス（息遣い）を再現して歌うことができるモデルを作成することを目的としています。教師となる人間の声をWAVファイルとして録音し、そこから特徴量を抽出・分析し、MIDIファイルなどと共に保存することで学習用データセットを作成します。
