RG Singing AI 技術資料 専門用語集

本書は『RG Singing AI Recording Tool v1.3.1 P3.4 — QC Table Markers』の技術資料に登場する、音楽・音声処理・音響学・機械学習・ソフトウェアエンジニアリングに関する専門用語を分類・解説した用語集です。

1. 音声処理・音響学・音楽に関する専門用語

【音響特徴量・分析】

  • F0（基本周波数 / Fundamental Frequency）
    声帯振動の周期に対応する周波数。知覚される音の高さ（音高 / ピッチ）に直接関連します。単位は Hz（ヘルツ）。
  • RMS（Root Mean Square / 平方平均平方根）
    音声信号の振幅（強さ・大きさ）を表す統計的指標。実効値とも呼ばれ、音量の目安として利用されます。
  • Log-Mel Spectrogram（対数メルスペクトログラム）
    人間の耳の周波数知覚特性（メル尺度）に基づいてフィルタリングした周波数成分（スペクトログラム）に対し、対数変換を行った時間・周波数の2次元特徴量。音色や音素の分析・モデル入力に多用されます。
  • スペクトル包絡（Spectral Envelope）
    複雑な周波数スペクトルの山（ピーク）を結んだ滑らかな外形線。声帯振動（励振成分）を除いた声道（喉や口の形状）による共鳴特性（音色や母音の特徴）を表します。
  • フォルマント（Formant）
    声道の共鳴によって強調される特定の周波数帯域。低い方から と呼ばれ、主に母音の識別や音質に関係します。
  • HNR（Harmonics-to-Noise Ratio / 調波対雑音比）
    音声に含まれる周期的な成分（調波）と非周期的な成分（雑音）の強さの比率。声のクリアさやノイズ感、かすれ具合（息声）の指標となります。
  • 有声音（Voiced Sound） / 無声音（Unvoiced Sound）
    有声音は発声時に声帯振動を伴う音（母音や「ま行」「な行」など）、無声音は声帯振動を伴わない音（「さ行」「か行」の子音や息の音など）。
  • 倍音（Harmonics）
    基本周波数（F0）の整数倍の周波数を持つ成分。音色の深みや豊かさを形成します。
  • オクターブ誤り（Octave Error）
    F0推定アルゴリズムが、本来の基本周波数の2倍（1オクターブ上）や1/2（1オクターブ下）の周波数を誤って基本周波数として検出してしまう現象。

【音楽表現・歌唱技法】

  • ビブラート（Vibrato）
    歌唱や演奏において、音高（ピッチ）を周期的に揺らす歌唱・演奏表現。
  • ポルタメント（Portamento） / グリッサンド（Glissando）
    ある音高から別の音高へ滑らかに音を移動させる演奏・歌唱技法。
  • レガート（Legato）
    音と音の間に切れ目を入れず、滑らかに続けて演奏・歌唱すること。
  • セント（Cent）
    平均律における音程の最小単位。1オクターブ＝1,200セント、半音＝100セントとして定量的に音高差を表します。
  • ブレス（Breath）
    歌唱における呼吸・息を吸う音、または息を吐く動作。

【デジタル音声・信号処理】

  • PCM（Pulse Code Modulation / パルス符号変調）
    アナログ音声信号を定期的に標本化・量子化してデジタルデータに変換する最も基本的な音声フォーマット（WAVファイル等で使用）。
  • サンプリング周波数（Sampling Rate / Frequency）
    1秒間あたりの音声信号の標本化（採寸）回数。単位は Hz（例: 44,100 Hz = 1秒間に44,100回のデータを記録）。
  • モノラル（Monomorphic / Mono）
    単一のオーディオチャンネルで構成された音声。
  • フレーム（Frame）
    時間とともに変化する音声を分析するために切り出した短時間（数十ミリ秒程度）の区間単位。
  • ホップ長（Hop Length）
    隣り合う分析フレーム同士の開始位置の間隔（ずらし幅）。
  • 窓関数（Window Function）
    フレーム単位に切り出す際、端部の不連続による歪みを抑えるために乗算する関数（ハニング窓など）。
  • FFT（Fast Fourier Transform / 高速フーリエ変換）
    時間領域の波形データを周波数領域の成分に高速で分解・変換するアルゴリズム。
  • クリッピング（Clipping）
    入力信号の振幅が許容最大値を超えたことで波形の頂点が潰れ、ひずみが生じる現象。
  • DCオフセット（DC Offset）
    音声波形の中心軸（ゼロクロスライン）が直流成分（0V）から上下にズレてしまう現象。

2. 機械学習・AI・データサイエンスに関する専門用語

  • 教師データ（Training Data / 教師信号）
    機械学習モデルに学習させるための「入力データ」と「正しい出力（正解ラベル）」の組み合わせ。
  • アノテーション（Annotation）
    データ（音声・画像など）に対して、歌詞、音素、音程、タイミング境界などの意味情報（ラベル）を付与する作業。
  • アラインメント（Alignment）
    音声波形データと歌詞・音素・MIDI等のテキスト/記号データとの時間的な位置合わせ・対応付け。
  • データセット（Dataset）
    モデルの学習・検証・テストのために収集・整理・構造化されたデータの集合。
  • 過学習（Overfitting）
    モデルが訓練データだけに過剰に適合してしまい、見たことのない未知のデータに対する予測・生成精度が低下する現象。
  • データリーク（Data Leakage）
    本来テスト・検証用データとして分けるべき情報が学習用データに混入し、評価結果が不当に良く見えてしまう問題。
  • ベースライン（Baseline）
    新しい手法やモデルの性能を比較・評価する際の基準となる、標準的かつシンプルな既存モデルやシステム。
  • 代理指標（Proxy Metric / Proxy Indicator）
    直接測定することが困難な対象の代わりに、その妥当性の目安として利用する参考値（例: f0_confidence_proxy）。
  • 音響モデル（Acoustic Model）
    歌詞や楽譜などの言語・音楽的情報から、音響特徴量（メルスペクトログラムやF0など）を予測・生成する機械学習モデル。
  • ボコーダー（Vocoder）
    メルスペクトログラムなどの音響特徴量を、最終的な聴取可能な音声波形へ変換・復元するモデル/アルゴリズム。
  • 評価指標（QC精度評価）
    • 真陽性（TP）: 異常（問題あり）を正しく異常と検出すること。
    • 偽陽性（FP）: 正常なデータを誤って異常と検出すること（誤検知）。
    • 真陰性（TN）: 正常なデータを正しく正常と判定すること。
    • 偽陰性（FN）: 異常なデータを見逃して正常と判定すること（見落とし）。
    • 適合率（Precision）: 検出した問題候補のうち、実際に正しかった割合。
    • 再現率（Recall）: 実際に存在する問題のうち、正しく検出できた割合。

3. ソフトウェア・システムエンジニアリングに関する専門用語

  • QC（Quality Control / 品質管理）
    製品やデータの品質基準を満たしているかを検証・担保する一連の管理プロセス。
  • GUI（Graphical User Interface）
    画面上のボタンやウィンドウなど、視覚的・直感的に操作できるユーザーインターフェース。
  • MIDI（Musical Instrument Digital Interface）
    電子楽器やコンピュータ間で演奏情報（音符の高さ、長さ、強さなど）を伝達するための統一規格。
  • NPZ
    Pythonの数値計算ライブラリ「NumPy」において、複数の配列（Array）データをまとめて非圧縮/圧縮保存する標準ファイル形式（.npz）。
  • メタデータ（Metadata）
    データに関するデータ。音声データに付随する録音日時、話者ID、ファイル長、ハッシュ値などの属性情報。
  • SHA-256
    任意のデータから256ビットの固定長ハッシュ値を計算する暗号学的ハッシュ関数。データの破損や改ざん、改変がないかのチェック（完全性確認）に使用されます。
  • パディング（Padding）
    配列やデータ長を一定のサイズに揃えるため、データの前後や末尾に0などの固定値を埋め込む処理。
  • NaN（Not a Number） / Inf（Infinity）
    コンピュータの浮動小数点数における「非数（計算不能・未定義）」および「無限大」を表す特殊な値。
  • Python仮想環境（Virtual Environment）
    プロジェクトごとに独立したPython実行環境（ライブラリ依存関係）を作成・管理する仕組み。
  • テレメトリ（Telemetry）
    ソフトウェアの使用状況やエラーログなどを遠隔地のサーバーへ自動送信・収集する仕組み。
