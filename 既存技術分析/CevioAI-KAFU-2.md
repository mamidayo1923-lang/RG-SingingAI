# 技術調査報告書：音楽的同位体 可不 (CeVIO AI) における歌声合成技術の解析と考察

## 概要 (Abstract)

本報告書は、KAMITSUBAKI STUDIO所属のバーチャルシンガー「花譜」の歌声データを元に開発されたAI歌声合成ソフト「音楽的同位体 可不 (KAFU)」（CeVIO AIエンジン搭載）について、その内部技術を構造的に解説・考察するものである。公式情報・技術提供元の学術論文および公開済みの技術仕様を基盤に、確立された技術的知見と未公表部分を整理し、ディープラーニング音響処理技術の観点から包括的な技術分析を行う。

## 2. 公式・関連情報源から確認される技術仕様

テクノスピーチ社、CeVIOプロジェクト、および日本音響学会やICASSP等での論文発表において確認されている技術仕様は以下の通りである。

### 2.1 畳み込みニューラルネットワーク（CNN）によるパラメータ予測

従来の素片波形接続型（VOCALOID等の初期手法）やHMM（隠れマルコフモデル）型とは異なり、時系列畳み込みネットワーク（CNN）を中心としたディープラーニングモデルを採用している。

* **入力フレーム (Input Context)**:

  * 楽譜情報（音符の音高・長さ・テンポ）

  * 歌詞情報（音素列、母音・子音の分類）

  * 文脈情報（前後の音符数個分のフレーズコンテキスト、発音位置）

* **予測・生成パラメータ (Output Feature Parameters)**:

  1. **音素デュレーション (**$T_{dur}$**)**: 各音素の発声長およびタイミング。

  2. **基本周波数 (**$F_0$**) 軌跡**: メロディに対する微妙な揺らぎ、立ち上がり（しゃくり）、語尾のピッチフォール。

  3. **ビブラートパラメータ**: 開始遅延時間、振幅、周期的な周波数変動。

  4. **スペクトル包絡 (Spectral Envelope)**: 声質や母音・子音の音色変化。

  5. **非周期性指標 (Aperiodicity / AP)**: 息漏れ成分、かすれ感、擦過音の強度比率。

### 2.2 前後文脈（Context）を意識したフレーズ全体の表現

単一の音符や過小なフレーム単位での最適化ではなく、**前後の楽譜コンテキストを跨いだ大局的な予測**を行う。CNNにおける全畳み込み（FCN）構造を利用し、数秒から数十秒単位（セグメント）の長期依存関係を一括処理する。これにより、「高音に向かうフレーズ手前での準備的なピッチ変動」や「曲の展開に応じた歌い方のニュアンス変化」といった、人間に特有の巨視的な表現を自動再現する。

### 2.3 エディタ連動型リアルタイム再生成機構

ユーザーがCeVIO AIエディタ上でピッチ曲線やタイミングを手動調整した際、ピッチの変化に伴って「声質（スペクトル包絡）」や「息成分（非周期性指標）」が自動的に干渉・補正されるインタラクティブ構造を持つ。

## 4. 学術的・技術的視点からの分析と考察

テクノスピーチ社が著した学会発表論文（ICASSP、Interspeech、日本音響学会研究発表会等）およびCeVIO AIの動作特性から分析される内部技術を記述する。

### 4.1 音響モデル：FCNを用いた時間単位制御型 CNN アーキテクチャ

CeVIO AIは手動でパラメータを変更した際、即座に全フレーズが再計算・再描画される。この高速な応答性から、計算負荷の高い自己回帰型モデル（例: Tacotron 2等）ではなく、**非自己回帰型（Non-Autoregressive）のCNN（全畳み込みネットワーク: FCN）基盤のアーキテクチャ**を採用している。

テクノスピーチ社の発表論文（*Fast and High-Quality Singing Voice Synthesis System based on Convolutional Neural Networks*）に基づくと、音響モデルは以下の2段階処理で構成される：

1. **フレーム単位処理**: 楽譜特徴量を音素単位・状態単位（音素を複数分割した時間単位）で高速に処理。

2. **セグメント単位処理**: 時間的な長距離依存関係を畳み込み処理によって一括処理し、パラメータ生成アルゴリズム（MLPG等）を介さずに滑らかな $F_0$・スペクトル包絡・AP軌跡を直接計算。

```
[ 楽譜 / 歌詞 / 文脈入力 ]
       │
       ▼
 [ 状態 / フレーム単位変換層 (1×1 Conv) ] ──> [ Duration / Timing Predictor ]
       │                                           │
       ▼                                           ▼
 [ セグメント一括統合層 (1×n Conv / FCN) ] ───> [ 状態・フレーム展開 ]
       │
       ▼
 [ 音響特徴量生成器 ] ──> ($F_0$, スペクトル包絡, 非周期性指標 AP)
       │
       ▼
 [ ボコーダー部 ] ──> [ 音声波形出力 (24kHz/48kHz) ]

```

### 4.2 ボコーダー部：周期/非周期成分分離型ニューラルボコーダー (PeriodNet)

「可不」の最大の声質的特徴は、オリジナル歌手である「花譜」が持つ独自の「強い吐息感」「子音の擦過音」「語尾の独特なかすれ」である。

テクノスピーチ社は、歌声合成に特化した非自己回帰型ニューラルボコーダーとして「PeriodNet」（周期性解析に基づくニューラルボコーダー）に関する技術を発表している。この知見を考慮すると、以下の構造が適用されている：

* **周期/非周期成分の明示的モデル化**:
  歌唱音声に含まれる「ピッチ（周期成分）」と「吐息・子音（非周期成分）」を独立または明示的に分離して学習・生成する構造を持つ。これにより、ピッチ変更時の音質劣化を抑止しつつ、息漏れやハスキー感を高精度に再現する。

* **インタラクティブ編集との親和性**:
  $F_0$（ピッチ）・スペクトル・AP（非周期性指標）を条件ベクトル（Conditioning Vector）としてボコーダーに付与することで、ユーザーがCeVIO AIエディタ上で描いた任意のパラメータ操作に対して破綻のない自然な波形生成を可能にしている。

### 4.3 音素境界抽出と事前学習（Transfer Learning）

1. **Forced Alignment（強制アライメント）**:
   学習時にはCTC（Connectionist Temporal Classification）やHMMベースの音素アライメントにより、歌唱データのテキストと音声をフレーム単位で精密に同期させている。

2. **転移学習 (Transfer Learning / Fine-Tuning)**:
   単一の歌手データのみで高品質な音響モデルを構築するのはデータ量の観点から困難である。テクノスピーチ社が保有するマルチスピーカー/マルチシンガーの大規模ベースモデルで事前学習（Pre-training）を行い、そのモデルに対して「花譜」の歌唱データでファインチューニングを行うことで、少量の収録データからでも高い追従性を実現している。

## 5. 総括

「可不 (CeVIO AI)」は、単なる波形接続や一般的な音声ディープラーニングの適用にとどまらず、以下の技術的特徴の統合によって成立している。

1. **学術的系譜に裏付けられた特徴量設計**: 名古屋工業大学・テクノスピーチ社の長年の知見である「$F_0$・スペクトル包絡・非周期性指標」のパラメータ分離と制御。

2. **効率性と制御性を両立したモデル構成**: FCN（全畳み込みネットワーク）を用いた非自己回帰型音響モデルによる高速演算とユーザーコントロール性の両立。

3. **歌手特性の再現**: PeriodNetをはじめとする周期/非周期成分の独立・統合モデル化による、唯一無二のハスキーな歌声表現。

今後、Diffusionモデルをはじめとする最新の波形・特徴量生成アーキテクチャとの融合が進むことで、更なる表現力の向上が期待される。
