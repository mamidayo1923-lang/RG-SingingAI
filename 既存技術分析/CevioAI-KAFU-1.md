# 技術調査報告書：音楽的同位体 可不 (CeVIO AI) における歌声合成技術の解析と考察

---

## 概要 (Abstract)
本報告書は、KAMITSUBAKI STUDIO所属のバーチャルシンガー「花譜」の歌声データを元に開発されたAI歌声合成ソフト「音楽的同位体 可不 (KAFU)」（CeVIO AIエンジン搭載）について、その内部技術を構造的に解説・考察するものである。公式情報・技術提供元の学術的背景を基盤に、公開済み技術の範囲と未公表部分を整理し、最新のディープラーニング音響処理技術の知見から技術的推測を行う。

---

「可不」の歌声合成プラットフォームは、主に以下の3者の提携および技術提供により構築されている。

| 構成主体 | 担当役割 | 主な技術・資産 |
| :--- | :--- | :--- |

| **CeVIO プロジェクト** | プラットフォーム開発・GUI提供 | 歌唱エディタ（CeVIO AI Editor）の開発およびUI/UX実装 |

## 2. 公式・関連情報源から確認される技術仕様

テクノスピーチ社、CeVIOプロジェクト、および日本音響学会等の関連発表において公開・確認されている技術仕様は以下の通りである。

### 2.1 畳み込みニューラルネットワーク（CNN）によるパラメータ予測
従来の素片波形接続型（VOCALOID等の初期手法）やHMM（隠れマルコフモデル）型とは異なり、時系列畳み込みネットワーク（CNN）を中心としたディープラーニングモデルを採用している。

* **入力フレーム (Input Context)**:
  * 楽譜情報（音符の音高・長さ・テンポ）
  * 歌詞情報（音素列、母音・子音の分類）
  * 文脈情報（前後の音符数個分のフレーズコンテキスト、発音位置）
* **予測・生成パラメータ (Output Feature Parameters)**:
  1. **音素デュレーション ($T_{dur}$)**: 各音素の発声長およびタイミング。
  2. **基本周波数 ($F_0$) 軌跡**: メロディに対する微妙な揺らぎ、立ち上がり（しゃくり）、語尾のピッチフォール。
  3. **ビブラートパラメータ**: 開始遅延時間、振幅、周期的な周波数変動。
  4. **スペクトル包絡 (Spectral Envelope)**: 声質や母音・子音の音色変化。
  5. **非周期性指標 (Aperiodicity / AP)**: 息漏れ成分、かすれ感、擦過音の強度比率。

### 2.2 前後文脈（Context）を意識したフレーズ全体の表現
単一の音符や過小なフレーム単位での最適化ではなく、**前後の楽譜コンテキストを跨いだ大局的な予測**を行う。これにより、「高音に向かうフレーズ手前での準備的なピッチ変動」や「曲の展開に応じた歌い方のニュアンス変化」といった、人間に特有の巨視的な表現を自動再現する。

### 2.3 エディタ連動型リアルタイム再生成機構
ユーザーがCeVIO AIエディタ上でピッチ曲線やタイミングを手動調整した際、ピッチの変化に伴って「声質（スペクトル包絡）」や「息成分（非周期性指標）」が自動的に干渉・補正されるインタラクティブ構造を持つ。

## 4. 学術的・技術的視点からの分析と推測

テクノスピーチ社が著した学会発表論文（ICASSP、日本音響学会研究発表会等）およびCeVIO AIの動作特性から推測される内部技術を記述する。

### 4.1 音響モデル：非自己回帰型 (Non-Autoregressive) ネットワークの採用
CeVIO AIは手動でパラメータを変更した際、即座に全フレーズが再計算・再描画される。この高速な応答性から、計算負荷の高い自己回帰型モデル（例: Tacotron 2等）ではなく、**非自己回帰型（Non-Autoregressive）モデル（例: FastSpeech 2 または Conformer ベース）**を基調としている可能性が極めて高い。

```
[ 楽譜 / 音素入力 ]
       │
       ▼
 [ Encoder (Conformer/CNN) ] ──> [ Duration Predictor ] ─┐
       │                                                 ├─> [ Frame-level Alignment ]
       ▼                                                 │
 [ Pitch / Energy Predictor ] ───────────────────────────┘
       │
       ▼
 [ Acoustic Feature Generator ] ──> (F0, Mel-Spectrum, Aperiodicity)
       │
       ▼
 [ Neural Vocoder ] ──> [ 音声波形出力 (24kHz/48kHz) ]
```

### 4.2 ボコーダー部：非周期性指標 (Aperiodicity) 統合型 HiFi-GAN
「可不」の最大の声質的特徴は、オリジナル歌手である「花譜」が持つ独自の**「強い吐息感」「子音の摩擦擦過音」「語尾の独特なかすれ」**である。

テクノスピーチ社は2020年〜2022年にかけて「非周期性指標を考慮したGANベースのニューラルボコーダ」に関する論文を公表している。この知見を考慮すると、以下の技術が用いられていると推測される：

* **パラメータ結合型 GAN ボコーダー (Conditional GAN Vocoder)**:
  純粋なEnd-to-End型（音素から直接波形を出力）では、ピッチや音質をユーザーが直接編集する際の声質崩れ（Artifacts）が発生しやすい。これを回避するため、**$F_0$（ピッチ）・スペクトル・AP（非周期性指標）を明示的にパラメータとして分離抽出**し、それを条件ベクトル（Conditioning Vector）として **HiFi-GAN のような超高速生成ネットワーク** に流し込んでいると考えられる。
* **息成分の独立制御**:
  AP（非周期性）パラメータを分離・保持することで、ピッチ操作を行った際にも「息漏れの比率」や「声のハスキー感」が破綻せず、可不固有の声質キャラクターを保ったまま合成が可能となっている。

### 4.3 音素境界抽出と事前学習（Transfer Learning）
1. **Forced Alignment（強制アライメント）**:
   学習時にはCTC（Connectionist Temporal Classification）やHMMベースの音素アライメントにより、歌唱データのテキストと音声をフレーム単位で精密に同期させている。
2. **転移学習 (Transfer Learning / Fine-Tuning)**:
   単一の歌手データのみで高品質な音響モデルを構築するのはデータ量の観点から困難である。テクノスピーチ社が保有するマルチスピーカー/マルチシンガーの大規模ベースモデルで事前学習（Pre-training）を行い、そのモデルに対して「花譜」の歌唱データでファインチューニングを行うことで、少量の収録データからでも高い追従性を実現していると考えられる。

## 5. 総括

「可不 (CeVIO AI)」は、単なる波形接続やディープラーニングの適用にとどまらず、以下の技術的ブレイクスルーの結集によって成立している。

1. **学術的系譜に裏付けられた特徴量設計**: 名古屋工業大学・テクノスピーチ社の長年の知見である「$F_0$・スペクトル包絡・非周期性指標」のパラメータ分離。
2. **編集性を重視した明確な制御構造**: 非自己回帰型モデルによる高速演算とユーザーコントロール性の両立。
3. **歌手特性の再現**: 息成分（非周期性成分）に着目したニューラルボコーダー設計による、唯一無二のハスキーな歌声表現。

今後、Diffusionモデルなどの最新音声生成アーキテクチャとの融合が進むことで、更なる表現力の向上が期待される。
